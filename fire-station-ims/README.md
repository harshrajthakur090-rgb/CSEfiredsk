# FireDesk – Fire Station Incident Management System

A simulated dispatch system for assigning fire-response resources (vehicles and crew) to incidents.
CSE326 CA1 Project. Built with **HTML and CSS only**.

## Pages

| Page | File | Feature covered |
|---|---|---|
| Dashboard | `index.html` | Overview of active incidents, vehicles and crew |
| Report Incident | `report.html` | Incident intake, severity, location |
| Incidents | `incidents.html` | Active incident list with severity and status |
| Dispatch | `dispatch.html` | Crew and vehicle assignment, dispatch status tracker |
| Vehicles | `vehicles.html` | Vehicle availability |
| Crew | `crew.html` | Crew teams and assignment |
| History | `history.html` | Incident history with filters |
| Success | `success.html` | Confirmation after a form is submitted |

All pages share one stylesheet: `style.css`.

## How to run
Open `index.html` in any browser. No installation needed.

## Deploy on GitHub Pages
1. Upload all files to a public GitHub repository.
2. Go to **Settings → Pages**.
3. Under *Branch*, choose `main` and `/ (root)`, then click **Save**.
4. After a minute the site will be live at `https://<username>.github.io/<repo-name>/`.
